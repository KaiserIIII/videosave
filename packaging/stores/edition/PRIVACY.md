# VideoSave Commons privacy policy

VideoSave Commons opens a local extension tab. It does not read your other tabs, browsing history, accounts, or cookies. It has no analytics, advertising, registration, or telemetry service. It does not write the URLs you paste to extension storage.

When you select **Load file**, the extension requests the specific original media file you entered from `upload.wikimedia.org`. It first drops any query string or fragment. It never changes the request to another host, follows redirects, attaches your browser credentials, or supplies a referrer. Wikimedia receives the request and ordinary connection metadata, such as your IP address, in accordance with its own policy. [Wikimedia privacy policy](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy)

The downloaded bytes stay in the tab’s memory until you replace the input or close the tab. Clicking **Save file** uses the browser’s normal save flow. Your browser controls the saved file and its downloads history.

## 中文

VideoSave Commons 在扩展自己的本地标签页运行。它不读取其他标签页、浏览记录、账号或 Cookie，没有分析、广告、注册或遥测服务，也不会把粘贴的链接写入扩展存储。

点击「读取文件」后，扩展会去除链接中的查询参数和片段，只向 `upload.wikimedia.org` 请求你指定的原始文件。请求不跟随重定向，不携带浏览器登录凭据或来源页信息。维基媒体会收到此次请求和 IP 地址等正常连接信息。文件暂存在标签页内存中，直到更换链接或关闭标签页。点击「保存文件」会使用浏览器自己的保存流程，下载记录由浏览器管理。 [维基媒体隐私政策](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy)
