# VideoSave v1.2.0 Internal Security Audit Report

> **Scope Disclosure**: This is an internal engineering security audit conducted by the VideoSave maintainers on the `v1.2.0` codebase, installers, updater, Android APK, MCP server, and release pipeline. It is **not** an independent third-party security certification.

---

## 1. Audited Attack Surfaces & Mitigations

| Area | Threats Audited | Verified Control / Implementation | Verification Test |
| :--- | :--- | :--- | :--- |
| **Test Sandbox & DSH-12 Isolation** | Writes leaking into user real Downloads / configured `outDir`; symlink or Windows Junction escape; ambient env/companion hijacking; SQLite overwrite | `tools/preferences.mjs` (`--sandbox`, `VIDEOSAVE_NO_USER_SETTINGS=1`, `resolveThroughSymlinks` ancestor realpath check blocking symlinks/junctions/UNC paths BEFORE writes; `validate()` checks sandbox BEFORE SQLite persistence; strips ambient `MEDIA_TOOLKIT_URL` in sandbox); `tools/fs-audit-monitor.mjs` (`ReadDirectoryChangesW` / `FSEvents` / `inotify` + tree diff) | `tests/dsh12-fs-audit.test.mjs` (8 scenarios + junction escape), `tests/test-isolation-and-security.test.mjs` |
| **Windows `Setup.exe` & Uninstaller** | Zip-Slip path traversal in embedded payload; UAC privilege escalation; system PATH pollution; deleting user downloaded videos on uninstall | `installer/windows/VideoSaveSetup.cs` validates every extracted entry against `Path.GetFullPath(destDir)` prefix; per-user `%LOCALAPPDATA%` + `HKCU` only (zero admin/UAC, zero PATH edits); atomic `.staging` + `.rollback` swap; `tools/uninstall-windows.ps1` strictly preserves download folder | Automated `Setup.exe /S` sandbox install + `tests/ultimate-v1-1.test.mjs` |
| **Auto-Updater (`tools/updater.mjs`)** | Supply-chain hijack via arbitrary download URLs; MITM/tampered archives; silent remote code execution | `assertOfficialReleaseUrl` enforces strict `https://github.com/KaiserIIII/videosave/releases/download/` allowlist; downloads & parses official `SHA256SUMS.txt`; rejects SHA-256 mismatch before moving from `.part`; `autoExecuted: false` (never executes downloaded packages automatically) | `tests/v1.2-production.test.mjs` (tampered SHA-256 + untrusted URL rejection) |
| **Component Auto-Downloads (Node / FFmpeg / yt-dlp)** | Unverified binaries; mutable tags | Every auto-downloaded runtime in `tools/start-windows.ps1`, `tools/start-unix.sh` (macOS arm64/x64, Linux x64/arm64), and `tools/setup-platform-downloads.mjs` pins exact upstream version, source commit, and SHA-256 checksum; recorded in CycloneDX 1.6 SBOM | `tools/verify_release.py`, `tools/build_offline_windows.py` |
| **Android APK Signing & Permissions** | Committed private signing keys; overly broad storage permissions; WebView/JS injection | Zero `.jks`/`.keystore` files committed to Git; `tools/build_android_apk.py` separates release-signed (`-universal.apk`) vs ephemeral debug (`-debug.apk`); Android 10–16 uses Scoped Storage `MediaStore.Downloads` without `WRITE_EXTERNAL_STORAGE`; pure native Android UI (no untrusted WebView bridge) | `apksigner verify --verbose`, `aapt2 dump badging` |
| **Local HTTP Companion & `/console`** | DNS rebinding, CSRF, cross-origin theft, XSS | Loopback-only `127.0.0.1` binding + strict `Host` check; `HttpOnly; SameSite=Strict` pairing cookie + `Sec-Fetch-Site` / `Origin` CSRF validation; strict CSP (`default-src 'self'`, `frame-ancestors 'none'`); `X-Frame-Options: DENY`; pure DOM `textContent` rendering (zero `innerHTML` on untrusted data) | `tests/http-boundaries.test.mjs`, `tests/ultimate-v1-1.test.mjs` |
| **Headers, Cookies & Cross-Origin Isolation** | Cross-origin Cookie/Authorization leakage; private Referer path leakage; anti-bot challenge cookie replay | `tools/request-context.mjs` restricts `Cookie` & `Authorization` strictly to matching origin/domain/path/Secure; `Referrer-Policy` strips path/query on auto-observed cross-origin Referers; `tools/cookie-store.mjs` rejects challenge cookies (`cf_clearance`, `__cf_bm`, etc.) and never echoes raw cookie values to AI clients | `tests/request-context.test.mjs`, `tests/test-isolation-and-security.test.mjs` |
| **SSRF, Platform Short Links & Subprocesses** | `b23.tv` open redirect SSRF; arbitrary binary execution via `browserBinary`; ReDoS in `idPattern` | `resolvePlatformShortLink` uses `redirect: 'manual'` and verifies target resolves strictly to canonical `bilibili.com`; `resolveChromiumExecutable` enforces strict Chromium filename allowlist; `idPattern` bounded against nested-quantifier ReDoS; all child spawns use `execFile`/`spawn` arg arrays without shell interpolation | `tests/test-isolation-and-security.test.mjs`, `tests/v1.2-production.test.mjs` |
| **Diagnostic Export & Log Sanitization** | Credential or local path leakage in exported reports/stderr | `GET /api/diagnostics/export` returns only version/component/status summaries (zero pairing tokens, zero cookies, zero absolute user paths); FFmpeg error redaction strips query tokens and local paths | `tests/v1.2-production.test.mjs`, `tests/media-source.test.mjs` |

## 2. Privacy & Repository Hygiene Scan
- **Current `v1.2.0` working tree & all release archives**: Scanned against personal usernames, cloud-sync folder paths, personal media folder names, tokens, and `.jks`/`.keystore` files — **0 leaks in current branch and release packages**.
- **Historical Git Commits Disclosure**: Earlier commits prior to `v1.0.0` contained local workspace/folder paths in `docs/dsh-feedback-tracker.md` that were removed in subsequent commits. In accordance with open-source maintenance policy, public Git history has **not** been rewritten without explicit repository owner authorization. If full history scrubbing is desired, run `git filter-repo --replace-text` after archiving existing tags and force-push with owner approval.
