System Engineering

Layered Media Pipeline & Security Boundaries

Zero third-party npm dependencies. Built strictly on Node.js 24 standard modules, browser WebExtensions APIs, and local FFmpeg/FFprobe verification.

1. Unified Request Context

Propagates explicit Referer, Origin, and User-Agent consistently across Master Playlist, Media Playlist, Init, Segments, Byte-Ranges, Audio, Subtitles, AES-128 keys, Retries, Resume, Refresh, and FFmpeg fallback — while strictly blocking cross-origin Cookie and Authorization leakage.

2. Binary Content Inspector

Ignores misleading URL suffixes (.jpeg, .png, extensionless) and MIME types. Inspects actual binary container signatures (MPEG-TS, ID3-TS, custom-prefixed TS, fMP4/ISOBMFF, AES-128 post-decrypt plaintext) and strictly rejects HTML/JSON error pages, real images, corrupt payloads, and DRM boxes.

3. SHA-256 Checkpoint Recovery

Verifies every staged HLS segment, DASH fragment, and HTTP Range chunk with SHA-256 sidecars. Survives process crashes, network drops, service restarts, and signed URL refreshes while detecting and re-fetching only corrupted parts.

4. Smart Quality Negotiation

Supports best, max, auto, lowest, integer height caps, exact:HEIGHT, bitrate/byte budgets, and SDR/HDR preference across real observed variants, backed by post-download FFprobe verification.

5. Isolated Dedicated Browser Sessions

Supports custom User-Agent, browser selection, proxy routing, and dedicated VideoSave-managed profiles without ever touching system browser cookies, passwords, or history.

6. Clear Legal & Safety Scope

Designed strictly for public and authorized media. Never bypasses DRM, CAPTCHAs, Cloudflare challenges, or HTTP 403/401 restrictions; reports exact failure stages clearly.
